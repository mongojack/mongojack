Installation

If you're using maven, simply add the following dependency to your project:

<dependency>
    <groupId>org.mongojack</groupId>
    <artifactId>mongojack</artifactId>
    <version>6.0.1</version>
</dependency>

Gradle Groovy DSL:

implementation 'org.mongojack:mongojack:6.0.1'

Gradle Kotlin DSL:

implementation("org.mongojack:mongojack:6.0.1")

You can download the dependency directly from here:

http://repo1.maven.org/maven2/org/mongojack/mongojack/6.0.1/mongojack-6.0.1.jar

Source code can be obtained from the GitHub project.
